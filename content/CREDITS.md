# Artwork & credits

## Adorn branding

This wiki uses the supplied **Adorn wordmark v4**, copied from the release artwork. The original PNG remains unchanged.

## Typography

Headings, navigation and controls use the same Dumbledor typeface supplied with Adorn. The font is credited to **Graham Meade / GemFonts**. Its accompanying [usage notice](../assets/gemfont.txt) is included with the copied font.

Long-form body copy uses your device's system fonts for comfortable reading. The four colour themes use Adorn's interface palette with opaque backgrounds suited to reading outside the game.

## Documentation

The guides are generated from the maintained Adorn and ASF documentation. Player instructions, author tools and technical reference have separate navigation, and release/testing boundaries remain visible.
